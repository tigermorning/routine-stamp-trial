# 도장판 체험판

- 칸 세 개에 도장만 찍는 아주 단순한 루틴표 시안
- 계획표를 짜지 않고 일단 시작하는 것이 목적
- 지인 체험용이라 기능과 그림은 바뀔 수 있음

## 쓰는 법

- 오늘 칸을 누르면 진한 도장(다 했어요), 한 번 더 누르면 연한 도장(조금만 했어요), 또 누르면 비움
- 연한 도장도 그날은 한 걸로 침
- 도장 찍은 날이 3일, 7일, 14일이 되면 칸이 하나씩 열림 (최대 6칸)
- 처음 여는 사람에게는 새 칸 열기에 1일을 미리 채워 줌 (첫 도장 선물)
- "쌓인 것" 카드에 이어간 날, 최근 7일, 도장 수를 보여 줌. 줄어드는 숫자는 없음
- 맨 아래 "의견 보내기"에서 글을 복사해 보내 주면 됨

## 언어

- 한국어, English, 简体中文, 繁體中文
- 화면 맨 위 버튼으로 바꿀 수 있고, 고른 언어는 기억함
- 처음에는 브라우저 언어를 따라감

## 저장

- 기록은 쓰는 기기의 브라우저에만 저장됨
- 계정이나 로그인 없음
- 브라우저 사이트 데이터를 지우면 기록도 지워짐
