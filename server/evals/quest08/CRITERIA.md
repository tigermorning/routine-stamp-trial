# 내보낼 기준 (실험 전에 먼저 적음 — 2026-11-09)

문제: 답 생성 단계가 `REPLY_TOKENS=450` 한도를 숨은 생각에 다 써서 답이 비거나(16/60) 문장 중간에서 끊김(16/60).
데이터셋 `stamp-quest08-empty-reply`: 문제 항목 16(빈 답) + 정상 항목 16(비지 않고 한도 전에 끝남).

한 변형이 «내보낼 만하다»려면 아래를 모두 만족해야 한다.
1. 문제 항목 16개 중 빈 답 ≤ 1개.
2. 정상 항목 16개는 모두 비지 않은 답(done.ok=true)이고 한도(출력 토큰 ≥ 450)에 걸려 끊기지 않는다 — 나빠진 것이 없어야 한다.
3. 전체 32개 중 출력 토큰이 한도(450)에 닿아 끊긴 답 ≤ 2개(기준선은 문제 16 전부 + 정상 0).
4. 응답 시간 p90 ≤ 기준선 재생 p90 × 1.5.
5. 모드가 바뀐 항목(기준선 모드와 다름) ≤ 4개(모델 말투가 바뀌어도 고르는 모드는 대체로 유지).

시도할 변형(한 번에 한 가지): A) REPLY_TOKENS 450→1500, B) 답하기 전 생각 끄기(CLAUDE_THINKING=off). 기준선 재생(v1-replay)도 같은 조건으로 한 번 돌린다.
