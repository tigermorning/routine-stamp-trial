# [벤치마크 및 기술 사양서] 네이버 캘린더 스티커 & 메몽(Memong) 감성 메모 시스템

본 문서는 `routine-stamp-trial` 프로젝트에서 서연 님이 요구하신 핵심 벤치마크 2대 축(네이버 캘린더 스티커 시스템, 메몽 앱의 떡메모지·형광펜·데코 스티커)의 UX/UI 아키텍처와 구현 사양을 정의합니다.
클로드 코드는 서연 님의 요청 작업 시 반드시 본 사양서를 기준으로 코드를 작성합니다.

---

## 1. 벤치마크 선정 배경 및 제품 비전

루틴 도장판은 단순한 체크리스트가 아니라 **"궁극적으로 구글·네이버 캘린더를 대체하는 올인원 라이프 플래너"**로 진화합니다.
- **전체 스티커 시스템 ➔ [네이버 캘린더 벤치마크]**: 일정과 기분, 루틴을 직관적으로 시각화하는 카테고리 탭형 팩 피커와 또렷한 심볼 그래픽.
- **기록-메모지 & 꾸미기 ➔ [메몽(Memong) 앱 벤치마크]**: 삭막한 텍스트 박스를 탈피하여, 아기자기한 떡메모지 속지(모눈/줄/파스텔), 상단 마스킹 테이프, 글자 뒤에 그어지는 5색 형광펜(하이라이트), 메모지 위 다꾸 데코 스티커를 결합한 감성 아카이빙.

## 2. [전체 스티커 시스템] 네이버 캘린더 벤치마크 사양

### (1) 카테고리 5대 탭 분류 및 팩 구성
네이버 캘린더처럼 사용자가 상황과 기분에 맞춰 빠르게 찾을 수 있도록 **카테고리 탭(가로 스크롤 칩 바)**을 제공합니다.

1. **`daily` (일상·감정)**
   - 기분/표정: 빵긋 스마일, 하트 뿅, 꿀잠/하품, 불타는 의지, 눈물 찔끔, 멍때리기
   - 쉼/휴식: 커피 머그잔, 따뜻한 찻잔, 폭신한 침대, 헤드폰 음악, 욕조 힐링
   - 축하/기념: 생일 케이크, 선물 상자, 파티 폭죽, 반짝이 별
2. **`schedule` (약속·일정)**
   - 약속: 친구와의 만남, 식사/포크나이프, 카페 디저트, 영화 티켓, 쇼핑백
   - 이동/여행: 비행기, 기차/지하철, 자동차, 캐리어/짐가방
   - 생활/관리: 병원 십자가, 알약, 미용실 가위, 은행/지갑, 청소/빗자루
3. **`health` (운동·건강)**
   - 유산소: 아침 산책, 러닝화, 자전거, 수영
   - 피트니스: 덤벨/웨이트, 요가 매트, 스트레칭, 클라이밍
   - 데일리 케어: 물마시기(텀블러), 샐러드/식단, 비타민 챙기기
4. **`study` (공부·작업)**
   - 집중: 펼쳐진 책, 연필/노트, 노트북/코딩, AI 두뇌/반짝임
   - 일정 관리: 체크리스트, D-day 깃발, 시험 합격 부적, 모래시계/마감
5. **`weather` (날씨·계절)**
   - 햇살 쨍쨍, 뭉게구름, 촉촉한 비/우산, 소복한 눈, 일곱빛깔 무지개

### (2) 스티커 비주얼 스타일 규격
- **크기 및 뷰박스**: `viewBox="0 0 48 48"` (기본 규격 통일).
- **외곽선(Stroke)**: 또렷하고 부드러운 다크브라운/차콜 라인 (`stroke="#4a3b32"`, `stroke-width="2.2"`, `stroke-linecap="round"`).
- **채색(Palette)**: 눈이 편안하면서도 화사한 파스텔-웜톤 채색. 캘린더의 작은 셀(24~32px)에서도 형태가 뭉개지지 않는 단순·명료한 실루엣.
- **확장성**: SVG 심볼 스프라이트(`id="stk-{category}-{name}"`)로 등록하여 렌더링 성능을 극대화.

### (3) 스티커 피커 UI 인터랙션
- **상단 카테고리 탭 바**: `[전체] [일상] [약속] [운동] [공부] [날씨]` 칩 버튼 (가로 스와이프).
- **하단 스티커 그리드**: 4~5열 그리드, 탭 전환 시 0.15초 부드러운 페이드.
- **적용 위치**:
  - 루틴 슬롯의 대표 아이콘 변경
  - 주간/월간 캘린더 날짜 칸에 '오늘의 대표 스티커' 콕 찍기
  - 기록-메모지 위 다꾸 데코로 부착

## 3. [기록-메모지 컴포넌트] 메몽(Memong) 떡메모지 벤치마크 사양

### (1) 떡메모지(Tteok-memo) 속지 템플릿 4종
단순한 흰색 배경이 아닌, 다이어리 애호가들이 사랑하는 감성 떡메모지 스타일을 CSS로 경량 구현합니다.

1. **`grid-yellow` (연노랑 모눈 - 시그니처)**
   - 배경색: 은은하고 따뜻한 크림 옐로우 (`#fefce8` ~ `#fef9c3`)
   - 패턴: 18px 간격의 부드러운 격자선 (`repeating-linear-gradient` 모눈 패턴)
   - 테두리: 미세한 페이퍼 섀도우 (`box-shadow: 0 4px 12px rgba(91, 58, 46, 0.08)`)
2. **`lined-pink` (파스텔 핑크 줄노트)**
   - 배경색: 포근한 베이비 핑크 (`#fff1f2`)
   - 패턴: 22px 간격의 옅은 가로 줄노트선 (`rgba(244, 63, 94, 0.12)`)
3. **`blank-mint` (세이지 민트 무지)**
   - 배경색: 산뜻하고 차분한 소프트 민트 (`#f0fdf4`)
   - 패턴: 무지 속지 + 우측 하단 미세한 접힘(folded corner) 음영
4. **`soft-lavender` (코튼 라벤더)**
   - 배경색: 몽환적인 연보라 (`#faf5ff`)
   - 패턴: 도트(Dot) 그리드 패턴 (20px 간격 미세 점)

### (2) 상단 데코레이션: 마스킹 테이프 & 압정 핀
메모지 상단에 실제 테이프를 붙여 고정한 듯한 빈티지 데코 요소를 배치합니다.
- **마스킹 테이프**: 메모지 상단 중앙 또는 모서리에 비스듬히 붙은 반투명 테이프 (`background: rgba(254, 215, 170, 0.75)`, 양 끝 지그재그 또는 자연스러운 사선 커팅, `transform: rotate(-1.5deg)`).
- **압정/핀 핀(Pin)**: 선택 옵션으로 상단 중앙에 꽂힌 메탈릭/파스텔 원형 핀 SVG.

## 4. [메모지 하이라이트(형광펜) 효과] 메몽 벤치마크 사양

### (1) 컨셉
메몽 앱의 최고 인기 기능 중 하나인 **"손으로 슥 그은 듯한 반투명 형광펜 효과"**입니다. 텍스트를 가리지 않고 글자 뒤로 자연스럽게 스며드는 레이어를 연출합니다.

### (2) 5대 파스텔 형광펜 팔레트
1. **Lemon Yellow**: `rgba(254, 240, 138, 0.65)` (클래식 형광펜)
2. **Peach Pink**: `rgba(254, 205, 211, 0.65)` (감성 핑크)
3. **Fresh Mint**: `rgba(187, 247, 208, 0.65)` (눈이 편한 연두)
4. **Sky Blue**: `rgba(186, 230, 253, 0.65)` (차분한 하늘색)
5. **Soft Lavender**: `rgba(233, 213, 255, 0.65)` (은은한 보라)

### (3) 렌더링 CSS 구현 규칙
형광펜은 글자 전체를 사각형으로 덮는 것이 아니라, 실제 형광펜 닙(Nib)이 지나간 것처럼 글자의 아래 60% 영역을 받쳐주는 형태가 가장 자연스럽습니다:
```css
/* 자연스러운 마커 스트로크 */
.hl {
  background: linear-gradient(180deg, transparent 35%, var(--hl-c, rgba(254, 240, 138, 0.65)) 35%);
  border-radius: 2px;
  padding: 0 3px;
  box-decoration-break: clone;
  -webkit-box-decoration-break: clone;
}
.hl-yellow { --hl-c: rgba(254, 240, 138, 0.7); }
.hl-pink   { --hl-c: rgba(254, 205, 211, 0.7); }
.hl-mint   { --hl-c: rgba(187, 247, 208, 0.7); }
.hl-blue   { --hl-c: rgba(186, 230, 253, 0.7); }
.hl-purple { --hl-c: rgba(233, 213, 255, 0.7); }
```

### (4) 에디터 인터랙션
- 텍스트 입력창 상단/하단에 미니 형광펜 팔레트 바 제공: `[🟡] [🩷] [🟢] [🔵] [🟣] [⌫ 지우개]`.
- 드래그한 문장에 원하는 컬러를 탭하면 즉시 하이라이트 적용.
- 저장 포맷: 가벼운 마크다운 확장(`==텍스트==` 또는 `<mark class="hl hl-color">텍스트</mark>`)으로 로컬 스토리지에 무손실 저장.

## 5. [메모지 꾸미기 스티커(다꾸)] 메몽 벤치마크 사양

### (1) 데코 스티커 팩 구성
메모지 본문 위 여백이나 텍스트 주변을 꾸밀 수 있는 다꾸용 미니 스티커:
- 마스킹 테이프 조각 (가로 스트립, 사선 미니 테이프)
- 포인트 스티커: 붉은 하트, 반짝이 별, 당근, 클로버, 귀여운 곰돌이 얼굴
- 메모 핀/클립: 종이 클립, 컬러 압정, 메모 집게

### (2) 부착 인터랙션
- 메모지 편집 모드에서 [스티커 붙이기] 탭.
- 원하는 스티커를 고르면 메모지 우측 상단/빈 여백에 찰떡처럼 부착.
- 스티커마다 살짝 기운 자연스러운 랜덤 회전각(-4° ~ +4°) 자동 부여.
- 스티커 터치 시 [삭제], [레이어 순서 변경 (글씨 뒤로/앞으로)] 팝업 지원.

## 6. 점진적 기능 해금(Progressive Disclosure) 연동

클로드 코드는 서연 님의 '점진적 해금 철학'을 어기지 않도록 본 기능들을 단계별로 오픈합니다:

- **Tier 1 (0~3일차)**: 오직 3칸 도장판 유지 (신규 유저 보호).
- **Tier 2 (3~28일차)**: 
  - 슬롯 6칸 확장과 함께 **'오늘의 한 줄 떡메모지'** 1장 기본 해금.
  - 네이버 캘린더형 스티커 피커에서 '일상·운동' 기본 팩 오픈.
- **Tier 3 (28~60일차)**:
  - 떡메모지 4종 속지 템플릿 변경 기능 해금.
  - 5색 형광펜(하이라이트) 마킹 툴바 해금.
  - 메모지 다꾸 데코 스티커 팩 전면 해금.
- **Tier 4 (60일차 이상, 구글·네이버 캘린더 대체 모드)**:
  - 날짜별 캘린더 뷰에서 일별 도장 + 네이버 캘린더 스티커 + 메몽 메모지가 하나의 타임라인으로 완전 융합.

## 8. 클로드 코드를 위한 실전 구현 로드맵 (Checklist)

클로드 코드는 위 사양을 다음 4단계 순서로 `index.html`에 안전하게 구현합니다:
1. **1단계 (CSS 속지 및 하이라이트 구축)**: `.memo-pad`, `.tpl-grid-yellow`, `.masking-tape`, `.hl-yellow` 등 CSS 스타일을 먼저 정의.
2. **2단계 (네이버 캘린더형 스티커 탭 바)**: `ICONS` 및 `STICKER_PACKS`를 카테고리별(daily, schedule, health, study, weather)로 구조화하고 탭 스위처 UI 연결.
3. **3단계 (기록-메모지 컴포넌트 렌더링)**: `today` 카드 아래 또는 별도 접이식 섹션으로 떡메모지 UI 및 형광펜 툴바 마운트.
4. **4단계 (로컬 스토리지 동기화 및 테스트)**: `npm test`를 돌려 기존 3칸 도장판 해금 로직 무결성 검증.
